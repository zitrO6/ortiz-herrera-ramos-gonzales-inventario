# Inventario Tecnológico

## Integrantes

- Emmanuel Ortiz Herrera
- Matias Ramos Gonzales 

## Descripción

Aplicación frontend desarrollada en React para registrar y visualizar equipos tecnológicos disponibles en un inventario.

## Funcionalidades implementadas

- Registro de equipos tecnológicos.
- Registro de nombre, marca, categoría, precio, stock y estado.
- Validación de los campos del formulario.
- Visualización dinámica de los equipos registrados.
- Manejo del estado mediante useState.
- Uso de componentes reutilizables y props.
- Renderizado condicional de mensajes y estados.
- Diseño básico utilizando Bootstrap.

## Tecnologías utilizadas

- React
- Vite
- JavaScript
- Bootstrap
- Git
- GitHub

## Ejecución del proyecto

Instalar las dependencias:

```bash
npm install
```

Ejecutar el proyecto:

```bash
npm run dev
```
